Sentinel Security

A Python-Based File and URL Threat Detection Project

About the Project

Sentinel Security is a cybersecurity application being developed as a personal project to explore malware detection, file analysis, and threat intelligence.

The goal is to build a desktop security tool capable of analyzing files and URLs for potential threats.

This project combines cybersecurity principles with software engineering practices.

Current Features

SHA-256 file hashing

Basic file information analysis

Local malware hash database

Hash-based threat detection

Automated scanner tests

Technologies

Python 3.14

JSON

Git and GitHub

Python unittest framework

Planned Features

Suspicious URL detection

Threat intelligence API integration

Graphical user interface (GUI)

Advanced file analysis

Scan history and reporting

Project Status

Version: 0.3.1 — Early Development

Sentinel is an educational project and should not be used as a replacement for established antivirus software.
